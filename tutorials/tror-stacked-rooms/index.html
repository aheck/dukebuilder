Mini Tutorial: TROR: Two Stacked Rooms

We will make a large upper room with a square opening in its floor, and a smaller room directly below that opening. You can look and fly through the opening in 3D. No sprites, lotags, or sector effectors are needed.

TROR means True Room Over Room. Simply overlapping two rooms does not connect them. A TROR connection joins an upper floor to a lower ceiling at the same height, making an opening between them.

You can leave this mini tutorial open while you edit. Click the map viewport before using shortcuts. Save any existing work, then choose File → New.

1. Draw the larger upper room

  1. Set the grid size to 256 using the grid control in the status bar.
  2. Press Ctrl+D for Draw mode. Draw a square 16 grid cells wide and 16 cells tall. For an exact example, use corners (-2048, -2048), (2048, -2048), (2048, 2048), (-2048, 2048). The status bar shows the pointer coordinates.
  3. Click the first corner again to close the square.
  4. Press S for Sectors mode and click inside it. In the properties panel, set Ceiling Z to -16384 and Floor Z to 0. Keep slopes at zero.

Build heights run downward: a negative number is higher, and a positive number is lower. These are Build Z units, not the horizontal grid units.

2. Mark the smaller opening

  1. Press Ctrl+D. Inside the large square, draw another square 8 grid cells wide and tall: (-1024, -1024), (1024, -1024), (1024, 1024), (-1024, 1024). Close it by clicking its first corner.
  2. Press S and click inside the small square. Check that its ceiling is -16384 and floor is 0; set them explicitly if necessary. The surrounding upper sector should have the same heights.

The upper room now consists of two sectors: the surrounding floor and the small central sector. They look like one room because their heights match. The small sector will become the opening; do not delete it.

Do this before connecting TROR: the editor currently blocks drawing that repartitions an already connected sector.

3. Create the lower room

  1. With only the small central sector selected, choose Tools → TROR / Layers → Extend floor downward….
  2. Enter 16384 for the new room height and accept. The dialog warns that TROR reserves some panning and tag fields; these are unused in this new map.

The editor creates the lower room and automatically isolates it. Other geometry turns gray. The lower room has ceiling 0 and floor 16384. Its ceiling connects to the central upper sector's floor.

You have two visible rooms made from three sectors. Only the central square connects vertically. The surrounding upper floor stays solid. Extending the entire large sector instead would make both rooms the same size.

4. Look at the result in 3D

  1. If you have not configured textures yet, add DUKE3D.GRP under Settings → Game Data.
  2. Point inside the isolated lower room and press Q. You start in the lower room. Look upward: you should see the upper room's ceiling.
  3. Use the mouse to look and W/S to fly forward/backward. Look up and hold W to fly through the opening. This is a free-flight preview, not player movement with gravity or collision.
  4. Press T to show the connection as a solid labeled TROR plane on black. Press T again to see through it. This is an editor display toggle, not a floor added to the saved map.
  5. Press Q to return to 2D.

You can change ordinary floor, ceiling, and wall textures by pointing at a surface in 3D and right-clicking. Press Escape to clear a selection before editing just the pointed-at surface.

5. Switch between the two layers

In 2D, with the lower room isolated, choose Tools → TROR / Layers → Layer above. Both upper sectors become editable because they connect through ordinary walls. To go down again, press S, select the central opening sector, then choose Layer below. The surrounding floor has no downward connection.

Tools → Show all sectors removes isolation. The overlapping squares can then trigger a target chooser. Use layer isolation when you want unambiguous selection. Gray geometry is not deleted.

6. Place the player start and save

  1. Show all sectors and press T in 2D for Sprites mode (T has a different meaning in 3D).
  2. Select the player-start arrow and right-drag it onto the surrounding upper floor, for example (-1536, 0). Keep it away from the opening. If a target chooser appears, choose the upper surrounding sector.
  3. With the arrow selected, set its Z to -6144 in the properties panel. This puts it between the upper ceiling and floor.
  4. Press Ctrl+S and save as my-first-tror.map. The editor automatically uses map version 9 because the map contains TROR.

The connected planes share a bunch ID, shown in properties. You do not need to enter this number yourself. To play the map, use a TROR-capable EDuke32 setup; original Duke Nukem 3D does not support version-9 TROR maps. This example has no stairs or lift back up from the lower room.

If something looks wrong

  • The opening is black with TROR lettering: press T in 3D to turn off solid-plane display.
  • Layer below says there is no connection: select the upper central sector, not its surrounding floor.
  • Both rooms change when moving a corner: linked opening boundaries must match, even across hidden layers. To make the upper room larger, use the surrounding sector described above, not a stretched opening.
  • Drawing is rejected: finish the upper layout before extension. Undo the extension to revise it, then extend again. Repartitioning connected sectors is not supported yet.
  • Save rejects the player start: move it onto the solid upper floor and check its Z against the table above.
